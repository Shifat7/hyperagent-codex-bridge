## Exact platform blocker

Hyperagent's supported OAuth MCP tools create/read named-agent threads but do not provide a native Responses-compatible inference stream or per-request usage/cost metadata. The bridge therefore creates and polls one thread per sampling request, emits keepalives instead of true token deltas, and cannot attribute cost automatically.

Requested platform surface: documented OAuth + PKCE `POST /v1/responses`, standard SSE lifecycle/tool events, stable trace IDs, and machine-readable usage/cost.
